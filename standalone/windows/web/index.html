连接 Chrome 网页翻译

在扩展设置中输入当前服务地址和一次性配对码。

安装扩展
  1. 先解压 Chrome 扩展 ZIP。Chrome 的「加载已解压的扩展程序」不能选择 ZIP 文件。
  2. 打开 chrome://extensions，启用开发者模式，选择直接包含 manifest.json 的文件夹。
  3. 点击下方按钮生成配对码，复制到扩展设置完成配对。
  4. 在网页上点击翻译，或将当前站点加入自动翻译列表。
服务地址尚未生成配对码仅使用一次，5 分钟内有效。

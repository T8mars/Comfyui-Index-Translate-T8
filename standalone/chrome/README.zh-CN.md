无字幕语音以 320 ms 发送音频，只将 ASR 确认文本送入顺序翻译队列，保留确认前缀保护；长文本入队前完整拆分，结束时用会话 revision 游标排除重复历史。支持的播放速度取决于本机是否能跟上 ASR，积压会明确停止并提示，不静默丢音频。

1. 下载 [v0.1.20 Release](https://github.com/T8mars/Comfyui-Index-Translate-T8/releases/tag/v0.1.20) 的 `IndexTranslate-Chrome-v0.1.20.zip`，解压后目录直接包含 `manifest.json`。本工作区也备有 `dist/IndexTranslate-Chrome-0.1.20-unpacked`，或含 `chrome_index_translate` 外层目录的 `IndexTranslate-Chrome-0.1.20.zip`。不要在 Chrome 中选择 `.zip` 文件。
2. 在 `chrome://extensions` 开启开发者模式，点击「加载已解压的扩展程序」，选择上一步的 **文件夹**（不是其中某个文件）。已有扩展保持原目录并点击「重新加载」，无需重新安装或配对。
3. 在整合包 Chrome 配对页生成配对码；在扩展设置输入本机服务地址和一次性配对码。
4. 打开普通 HTTP/HTTPS 网页，右侧会自动出现「译」按钮，单击开始翻译，无需每次先点 Chrome 工具栏。播放器内会自动出现「字幕译」「语音译」「停止」按钮。若希望进入本站就开始翻译，可在扩展菜单勾选「自动翻译这个站点」。

0.1.16 使用静态内容脚本，让按钮在新网页、刷新和浏览器重启后常驻，不再依赖临时 activeTab 授权或站点自动翻译规则。为此扩展需要普通 HTTP/HTTPS 网站访问权限；Chrome 提示新增权限时请允许，并在扩展的「网站访问权限」中选择「在所有网站上」。升级已有解压扩展时覆盖原文件夹、重新加载扩展，再刷新网页，原配对和偏好保留。只显示按钮时不会发送正文或采集音频；点击翻译或已开启本站自动翻译时才处理正文，视频声音仍需主动开启。视频字幕区只显示原文和已返回的译文，等待时保留当前原文，不显示「翻译中」「识别中」等大字提示；失败或缺少授权时，仅在播放器按钮旁显示简短说明。

启用站点规则后，刷新自动翻译正文；滚动、动态新增段落和 SPA 路由切换会增量翻译。双语显示保留原文 DOM，代码、链接、公式作为占位符保留。可停止、还原、重试；还原后自动观察暂停，直到再次启动。关闭站点规则会停止已打开页面的自动任务。

网页中会显示 36 × 36 像素、蒂芙尼蓝色的「译」悬浮按钮，默认紧贴右边缘。点击进度面板外、按 Escape 或切换窗口时面板自动收起，翻译继续。设置页的「悬浮按钮回到右边」可重置已有拖动位置。可拖动到方便的位置，扩展会记住位置；单击可翻译当前页面并打开进度面板，面板可收起，也可停止、还原或重试。关闭本站自动翻译后，刷新仍保留悬浮按钮和播放器按钮，可随时手动点击。

0.1.14 的语音模型路径在整合包「模型与设备 → 视频语音识别」中选择，可直接复用已有 R2T2 文件。扩展继续使用你们已有的流式语音处理方案：标签页音频分块识别，显示识别预览，已确认的语音段落由 Index-Translate 翻译。播放器内提供「字幕译」「语音译」「停止」三个按钮，每个按钮只选择所在播放器。Chrome 首次采集某个标签页声音前，需要点击工具栏扩展入口授予 activeTab 权限；未授权时视频内会明确提示操作。以后同一标签页可直接使用视频内按钮。

## HTML5 视频翻译（0.1.15）

先运行含 R2T2 语音组件的 **0.1.13 完整离线 Windows 整合包** 并完成配对，然后打开视频所在标签页，点击扩展菜单的「视频翻译」。扩展优先读取该视频提供的标准 HTML5 `TextTrack` 字幕，在画面下缘显示原文与译文；没有标准字幕轨时，Chrome 在用户点击后采集当前标签页声音，独立整合包中的 R2T2 worker 流式识别，再交由 Index-Translate 翻译。播放器存在空字幕轨、自定义字幕无法读取时，可点击「直接识别声音」强制走音频路径。识别过程中先显示临时转写，语音段落结束后显示译文。点击「停止视频翻译」立即停止采集并恢复原生字幕显示。标签页音频仅送至本机 `127.0.0.1` 服务，不写入音频文件；采集期间扩展把原声接回系统扬声器。

0.1.15 增加播放器内按钮，支持动态播放器；0.1.16 在所有普通网页自动加载这些按钮。Vimeo iframe 优先通过官方播放器字幕接口获取 cue；接口不可用或没有字幕时回退到本地语音。连续切换/停止模式时会等待旧语音启动返回并取消，避免新会话抢占。设置页新增「重新加载扩展」入口：覆盖代码后刷新设置页即可重新加载，配对与偏好保留。

这是针对普通 HTTP/HTTPS 页面的通用 HTML5 视频路径，含第三方播放器 iframe 时可用标签页音频后备。更新扩展后 Chrome 会显示新增的标签页音频采集权限；采集仅在你点击视频翻译入口后启动。播放器自己绘制的字幕不能直接读取，会走音频识别。浏览器受保护播放、某些播放器全屏覆盖层、无声音轨及静音视频可能无法显示或识别。R2T2 预编译 CUDA 语音组件目前在 Windows 11 / RTX 5090 Laptop 上验证，其他显卡尚未实测。此版本新增 Python 依赖与约 2.19 GB 语音权重，旧 Windows 整合包仅靠 GitHub 代码更新无法启用语音模式；需要新的完整包。

0.1.12 将悬浮按钮缩至 36 × 36 像素，只保留「译」字；进度仍可在展开面板中查看。

0.1.11 将扩展名称统一为「T8 Index Translate 本地网页翻译」，新增可拖动、可收起的网页悬浮翻译按钮。此更新与 0.1.10 Windows 本地服务兼容。

设置支持 14 种常用目标语言、自动原文检测、JSON 术语表与视口优先。目标语言须明确。后台短任务协议持久保存任务 ID，避免长时间等待单次模型 HTTP 响应。缓存按服务身份、模型版本、推理精度、语言、提示词和术语区分，并使用逐条 IndexedDB 事务写入。

正文翻译只支持普通 HTTP/HTTPS 顶层网页；Chrome 内部页面、PDF 阅读器、iframe、Shadow DOM、表单编辑内容及图片内文字不在正文翻译范围。视频模式可用标签页音频覆盖 iframe 播放器。原文和译文仅保存在本机；设置页可清空译文缓存，整合包可撤销配对。翻译失败时保留原文并提示重试，预算截断或占位符异常不会被当作完整译文插入。

扩展只连接 `http://127.0.0.1:<端口>` 或 `http://localhost:<端口>`，配对凭据不向内容脚本暴露。扩展无需 Chrome 商店账户，当前交付为可加载的解压包。默认服务地址为 http://127.0.0.1:8098。

0.1.2 请配合 0.1.2 整合包使用：后台会校验任务的推理设置快照，避免设置切换期间污染缓存，并按 request_id 恢复和取消任务，即使提交响应丢失或后台 worker 重启也保留任务所有权。缓存不可用时仍可翻译。网页复用或移动正文节点、删除双语输出、从浏览器历史缓存恢复时会重新协调任务；正文中的字面占位符和 emoji 不会被内部拆分损坏。动态进入禁止翻译或编辑区域时移除译文，旧异步结果不能回写到替换后的正文记录。撤销站点权限会停止已经打开页面的任务；服务短暂不可达时，未完成的取消会保留并在后台重试。正在运行的页面使用启动时的语言和术语快照，再次「继续」会应用新偏好。手动停止或还原在当前页面的 SPA 路由切换后仍保持暂停，直到再次启动。

0.1.3 请配合 0.1.3 整合包使用。扩展在提交和恢复任务时绑定服务身份；如果本机端口换成另一套服务，会先提示重新配对，避免把旧页面正文发送给新服务。页面中的 `display: contents` 可见文字、行内容器内块元素两侧文字，以及包含块元素的受保护链接和公式已纳入翻译与保留检查。页面切换与提交恰好发生在同一毫秒时，新页面任务也不会被旧页面的停止标记误取消。

0.1.4 请配合 0.1.4 整合包使用。扩展现在跳过 Canvas/媒体元素内不显示的回退文字、`content-visibility: hidden` 和透明正文；这些内容在变为可见后才翻译。折叠的 `details` 只翻译可见的 `summary`，展开后再处理正文，重新折叠时移除隐藏译文。`<wbr>` 不再拆开单词，短标题也会翻译。

0.1.5 扩展翻译逻辑未改，请配合 0.1.5 整合包使用。Windows 服务和 WebUI 的任务记录清理及身份防护更新不改变站点授权、自动翻译或配对流程。

0.1.6 请配合 0.1.6 整合包使用。祖先设置 `visibility: hidden`、子元素明确恢复可见时，该子元素中的行内正文现在也能翻译；`ruby` 的注音不会混入模型原文。扩展补齐对象和 iframe 的隐藏回退文字、计量控件回退文字，以及 `legend`、`caption` 译文的位置检查；对象资源加载失败而回退文字确实可见时仍会翻译，并在资源加载状态变化后重新扫描。

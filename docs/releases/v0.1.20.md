## 中文

这次发布包含 0.1.18 / 0.1.19 的累计 BUG 修复和 0.1.20 的启动器、预热状态、声音翻译反馈。

- Windows 新增 **T8IndexTranslate.exe · By T8star**，启动后常驻任务栏。关闭窗口或点击「停止服务并退出」会先取消任务、关闭语音 worker、卸载翻译模型，再等待本包的服务退出。启动中关闭与重复启动也已验证。
- 「加载并预热」旁显示排队、加载/编译、验证、完成（绿色）或具体错误；刷新继续追踪，临时断网后恢复，可取消、重试。常规 eager 回退会明确说明。
- Chrome 「直接识别声音」点击后立即反馈准备/授权，随后显示模型加载、等待声音、采集秒数、暂停/结束或具体失败原因，重新打开弹窗可读取状态。停止与迟到启动应答已隔离。视频字幕区不显示进度大字。
- 累计修复：语音暂停/结束排空、跳转和后台重启的会话隔离；隐藏/重绘播放器与悬浮按钮恢复；配对撤销收尾；语音结束响应重试；下载提前断开的续传；量化清单检查；节点升级后的缓存失效。

### 下载与升级

1. **Chrome**：下载 `IndexTranslate-Chrome-v0.1.20.zip`，解压目录直接包含 `manifest.json`。已有用户覆盖原目录，重新加载扩展，再刷新网页；配对和偏好保留。Chrome 的声音授权、受保护视频和站点采集限制仍然适用。
2. **Windows**：已有 0.1.17 加速整合包先停止服务，再运行 `update.cmd`。也可将 `IndexTranslate-Windows-code-v0.1.20.zip` 直接覆盖解压到原整合包根目录，运行 `start.cmd`。为了兼容旧版更新器，EXE 在代码 ZIP 的 `app/` 内，启动时自动放到根目录，无需改名/搬文件。该 ZIP **不含 Python、运行时或模型**；0.1.16 及更旧包仍需作者分享的完整运行时升级。后续手动更新前关闭 EXE 窗口。
3. **ComfyUI**：下载 `IndexTranslate-ComfyUI-v0.1.20.zip` 或使用 ComfyUI Manager 更新，重启 ComfyUI 生效。节点在自己的 Python 中独立推理，不连接 Windows 服务。

模型目录可保持 `Index-Translate-2B`、`Index-Translate-9B` 或对应 `ConvRot-INT8` 名称，也可选择任意完整目录的绝对路径。Windows 可在界面选择翻译模型与已有 R2T2 语音模型目录；节点用 `model_path`。权重未变，无需重新下载。2B/9B 的首次编译等待仍存在，本次不是新的性能加速版本。

### 验证

Python 111 项及 4 subtest；预热前端 14 项；声音反馈 14 项；Chrome 生命周期 51 项；隔离 Chrome 真实加载。原生 EXE 8 项，包括中文空格路径、自带 Python、真实 2B ConvRot INT8 和 native R2T2 活动会话：关窗口后 worker/服务/GUI 退出，CUDA allocated/reserved 均为 0。代码 ZIP CRC/SHA256、旧 0.1.17 更新器升级与配置/模型保留另行验证。反馈检查使用受控授权/ASR应答，不代表所有视频网站和用户配置已完成音频授权。

## English

Version 0.1.20 adds a persistent **By T8star** Windows taskbar launcher, nearby warmup progress/completion/error status and immediate Chrome speech-start feedback. It includes the previously local 0.1.18/0.1.19 fixes for speech lifecycle, pause/end/seek isolation, worker recovery, renderer controls, pairing revocation, terminal response retries, resumable downloads and quantization metadata.

Existing 0.1.17 acceleration bundles: stop the service and run `update.cmd`, or extract the Windows code ZIP over the original bundle root and run `start.cmd`. The EXE is inside `app/` in this archive for legacy updater compatibility; the launcher installs it at the root automatically. No rename or manual move is needed. Closing the launcher cancels work, releases models/speech and waits for the owned service to exit. The ZIP excludes Python, runtimes and weights; earlier bundles still need a full runtime upgrade. Close the EXE before a later code update.

Extract the Chrome ZIP over the existing extension directory, reload it in `chrome://extensions` and refresh the page; pairing remains. The ZIP directly contains `manifest.json`. Chrome audio authorization and protected-playback restrictions still apply. Progress feedback remains outside the video subtitles. ComfyUI continues to run independently with its own Python and selectable complete model directories. Weights are unchanged.

Validation includes 111 Python tests plus 4 subtests, 14 warmup UI checks, 14 speech-feedback checks, 51 Chrome lifecycle checks and 8 native launcher checks with real 2B INT8/R2T2 resources released to zero CUDA allocated/reserved memory. Controlled capture/network fixtures do not establish support for every website.
